# Conceptual Research / Idea Archive

**Status:** NON-AUTHORITATIVE WORKING LIBRARY  
**Purpose:** Preserve concept seeds, observer artifacts, challenge cases, analogies, speculative causal phenomena, and future-facing ideas that may be valuable later without promoting them into current project truth.

## Authority rule

Material in this directory is **not** simulation semantics, historical evidence, architecture, implementation scope, or a decision merely because it is preserved here.

Conceptual artifacts may:

- preserve a causal observation worth revisiting;
- suggest distinctions future simulation machinery might need to express;
- serve as challenge cases for later design;
- preserve project-culture/observer material whose provenance matters;
- retain complete source material so later work need not reconstruct it from chat memory.

They may not silently:

- amend the Project Seed;
- alter accepted decisions/ADRs/specifications;
- create implementation requirements;
- substitute for historical research;
- promote a narrative regularity into a mechanic.

If future work wants to use a conceptual artifact consequentially, retrieve the source, reconcile it against then-current authority/evidence, and use the normal research/design/decision/promotion path.

## Collections

`THE_URUK_ACCIDENT/`
