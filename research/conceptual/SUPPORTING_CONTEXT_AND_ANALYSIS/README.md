# Supporting Context and Analysis

**Status:** NON-AUTHORITATIVE SOURCE / ANALYSIS COLLECTION  
**Authority:** None. Material here does not define simulation semantics, historical facts, governance, architecture, implementation scope, or accepted project decisions.

## Purpose

This directory preserves supporting observer material around the Uruk / Wonder Gather conceptual work.

The collection is intentionally mixed. It includes:

- analytical synthesis;
- observer-commission instructions;
- first-contact conceptual prompts;
- project/process explanation;
- provenance and transfer context.

Do not assume that every vivid distinction in these files is a new concept family.

For the idea-level reconciliation of this collection, see:

`../ingestion/2026-09-24/C_SUPPORTING_CONTEXT_RECONCILIATION.md`

## Reconciliation summary

The 2026-09-24 Wave C reconciliation found a small genuinely reusable delta amid substantial overlap and context.

Strongest new future seams:

- **institutional epistemic routing / epistemic constitution** — conventions about which evidence, authority, artifact, or procedure can settle which kind of claim;
- **protected uncertainty / recognized non-decision** — an institution can preserve a question as explicitly unresolved rather than forcing settlement.

Strongest new cross-program challenge:

- **question transformation by institutional epistemic culture** — the same hard question can become a different problem before being answered because inherited evidence practices, roles, and salience structures route it differently.

Important extensions, not new top-level families, include:

- genre-conditioned institutional self-representation;
- symbolic continuity versus practice continuity;
- history and self-description becoming causal;
- artifact purpose selecting which causal ancestry remains salient;
- dimension-specific recoverability of state, meaning, authority, and creative continuity.

Already-absorbed core includes:

- office/holder separation;
- authority versus capability/influence/recognition;
- official versus causal genealogy;
- anti-collective-ghost grounding;
- role-conditioned salience;
- archival rupture and loss of omniscient in-world history.

## Use rules

Good use:

- retrieve a complete source when a later conceptual claim needs provenance;
- distinguish direct event, institutional self-description, observer interpretation, and unresolved question;
- use observer artifacts to generate or challenge causal questions;
- keep project/process analogy separate from simulation semantics;
- preserve uncertainty and disagreement.

Bad use:

- treat commission language as accepted mechanics;
- infer ancient historical practice from project roleplay;
- create a new concept family merely because a story or metaphor is memorable;
- promote AI/project-specific workflow directly into social ontology;
- treat the anthology as primary evidence for events it synthesizes.

The source files are preserved unchanged.
