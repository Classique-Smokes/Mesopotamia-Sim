# SFL v0 Bridge and Dependencies

**Status:** DURABLE NON-AUTHORITATIVE / PROVISIONAL GUIDING FRAMEWORK  
**Role:** Show how current work functions as a reference substrate for future institutional-dynamics questions.

## 1. Principle

Do not interrupt or expand SFL v0 to implement this conceptual program.

Instead, use v0 as the first empirical/reference test of lower-level mechanisms that later institutional work may reuse.

## 2. Slice map

### Slice 1 — lower-level social fabric

Expected substrate:

- stable person / relation / arrangement identity;
- explicit proposals, responses, resolution, commit;
- semantic history and causal predecessor references;
- deterministic cycle closure;
- typed relations that do not collapse into one social score.

Institutional relevance:

This establishes the social/material reality from which higher structures must be grounded.

### Slice 2 — subjective recognition

Expected substrate:

- objective state separate from actor knowledge;
- provenance-bearing KnownFact / Recognition;
- actor-specific disagreement / contested recognition;
- action gating by subjective state.

Institutional relevance:

This is prerequisite machinery for legitimacy, outsider recognition, disputed authority, documentary influence, and competing genealogies.

### Slice 3 — persistent household identity

Expected substrate:

- formation from prior lower-level evidence;
- persistent identity not reducible to current composition;
- provenance-bearing participation;
- operational lifecycle distinct from numerical identity;
- continuity through controlled turnover.

Institutional relevance:

This is the first proof that the simulation can reify a higher-order actor without making it primitive.

### Slice 4 — representative role / succession

Expected substrate:

- persistent role separate from holder;
- vacancy and succession;
- representative/office-mode action;
- role recognition.

Institutional relevance:

This is the first real office-continuity experiment and direct precursor to broader authority/institutional action.

### Slice 5 — delayed processes / checkpoint continuation

Expected substrate:

- future-influencing state remains explicit;
- continuation through time;
- stable-cycle checkpoint discipline;
- role/recognition/process state survives serialization/reconstruction.

Institutional relevance:

This tests whether persistence is robust beyond one in-memory run and whether institutional history is truly stateful rather than conversational.

## 3. What v0 should prove before this program becomes actionable

The following are useful future gates, not current acceptance requirements:

1. typed lower-level relations remain meaningfully distinct in actual code and history;
2. history/provenance is sufficient to explain why current social state exists;
3. subjective recognition can diverge from objective state without global omniscience;
4. household formation is causally downstream of lower-level evidence rather than a direct create command;
5. household identity survives selected turnover while remaining genealogically legible;
6. household capability derives from people/commitments/role state rather than magical aggregate power;
7. office succession preserves role identity without preserving occupant identity;
8. stable continuation/checkpointing preserves future-influencing institutional state.

If these fail, general institutional design should repair the substrate rather than layer abstractions over it.

## 4. What must not fossilize from v0

SFL v0 contains deliberate laboratory specifics.

Do not generalize automatically:

- household `FormationWarrant` shape to all institutions;
- household participation gates to all organizations;
- household head structure to all offices;
- v0 recognition categories to every social belief;
- stable-ID technical fallback into a social priority rule;
- current scoring coefficients into final agency;
- current grain/time parameters into historical economy;
- Active/Inactive/Dissolved household lifecycle into a universal institutional lifecycle.

The reusable lesson is primarily **causal structure and separability**, not specific household policy.

## 5. First post-v0 experiment if v0 succeeds

Before building a new institutional type, subject the existing household machinery to selected simplified institutional challenge cases.

Candidate examples:

- succession with contested recognition;
- archive/knowledge loss without identity loss;
- divergent official versus causal household genealogy;
- controlled split / descendant recognition;
- external actor misrecognition.

The purpose would be to discover which primitives actually generalize.

Only after that should the project consider a separate institutional reference laboratory.
