# Q01 — When Wonder Gather Speaks as One Thing

**Surface coverage:** INDIRECT / TRANSFORMED  
**Analytical stage:** native extraction only; no Uruk comparison

## Delivered question

What is the referent when the response says things like "Wonder Gather learned", "the project discovered", "the Conservatory translated", or "the project chose"? When is that shorthand useful or misleading?

## Native material in the response

The handoff never defines the grammatical subject `Wonder Gather` directly.

Instead it repeatedly decomposes project-level statements into separate truth and authority surfaces:

- **pp.2, 13–21:** project truth is distributed among canonical design documents, current-state routing, implementation code, validation history, playtest documents, tests, Git history, conversation memory, and newly added culture/rationale documents.
- **pp.22–25:** final creative authority belongs to the human Game Director; implementation agents have bounded engineering autonomy; experiential/design disagreements remain human-controlled.
- **pp.35–39:** the human Game Director, high-context design AI, implementation agents, repository, prompts, tests, and documents have different persistence and context-transfer roles.
- **p.38:** the response explicitly says there is no live shared multi-agent memory fabric. Context moves through repository artifacts, tests, the human owner, and handoffs.
- **pp.73–75:** the new Conservatory vocabulary is mnemonic and must not outrank plain engineering meaning.

At the same time, the handoff freely uses collective grammar such as "Wonder Gather is", "the project learned", "the project adopted", "the project wants", and "the project intentionally preserves".

## Native-position reconstruction

**Inference from the response, not an explicit self-definition:**

The document behaves as though `Wonder Gather` is a useful macro-level referent for a distributed project whose actual truth, authority, memory, implementation, and judgment live in different places.

Its own discipline is not to abolish collective shorthand, but to **resolve consequential claims downward** when precision matters:

- design claims -> Game Director / GAME_VISION;
- implementation claims -> code/tests;
- execution claims -> Validation;
- current milestone claims -> CURRENT_STATE;
- rationale -> DESIGN_RATIONALE / high-context integration;
- experiential acceptance -> Game Director.

This suggests that collective language is treated as acceptable compression when the underlying surface can still be identified.

## What the response does not establish

The handoff does **not** explicitly answer:

- whether the project itself is regarded as an actor;
- whether `Wonder Gather` refers to a social relation, artifact network, organization, human-AI collaboration, or something else;
- the point at which collective grammar becomes misleading;
- whether different project-level predicates require different underlying referents.

Those remain open after this artifact.
