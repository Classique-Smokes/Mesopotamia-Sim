# Possible Post-v0 Paths

**Status:** DRAFT / NON-AUTHORITATIVE  
**Role:** Preserve plausible future sequencing options without choosing a roadmap.

These paths are contingent on v0 results. They can be combined, reordered, or rejected.

## Path A — Household as institutional stress-test laboratory

After SFL v0 completion:

1. inspect actual household histories;
2. select simplified Uruk challenge cases;
3. determine which household primitives generalize;
4. identify where household-specific warrants/rules stop being adequate;
5. produce a mechanism-gap report.

Advantage: maximum reuse of tested machinery; discovers abstraction from evidence.

Risk: overfitting general institutional theory to household semantics.

## Path B — Office / authority reference extension

Use the successful representative-role machinery to deepen:

- office persistence;
- vacancy;
- appointment/succession;
- competing claimants;
- recognition of authority;
- scope;
- personal versus office action.

Advantage: closest extension to planned v0 Slice 4.

Risk: treating institutional persistence as primarily office succession.

## Path C — Artifact / documentary memory research program

Before implementation, research historical documentary practices and design:

- artifact identity;
- copies/derivatives;
- authority/authenticity;
- actor access/knowledge;
- official versus causal genealogy.

Advantage: unlocks historically rich institutional memory and non-agent causal objects.

Risk: large archival subsystem before action/authority use-cases justify it.

## Path D — Work / coordination / responsibility laboratory

Deepen individual and organizational behavior around:

- tasks;
- knowledge/skill;
- responsibility;
- delegation;
- coordination;
- effective centrality;
- workload and attention.

Advantage: supports institutions as actual work organizations rather than labels.

Risk: requires richer individual agency/capacity theory and may be premature immediately after v0.

## Path E — Historically bounded institutional laboratory

After mechanism research, select one bounded historical institutional context as the next reference laboratory.

Possible classes (not selections):

- temple administration;
- palace administrative office;
- workshop/production organization;
- merchant/credit network;
- council/assembly;
- military/retinue organization.

Selection should follow explicit historical-research scoping, not conceptual preference.

Advantage: forces general ideas against real evidence.

Risk: premature selection may make one institutional form seem universal.

## Path F — General institutional-dynamics reference model

Only after enough lower-level evidence exists, create a reference laboratory specifically for:

- higher-order identity;
- continuity;
- authority;
- capability;
- recognition;
- multiple genealogies;
- artifact/procedure persistence.

This should not begin with a universal implementation framework. It should begin with accepted semantic questions and challenge cases.

## Current non-decision

No path is selected.

The main near-term project remains SFL v0. The purpose of preserving these options is to make later choices deliberate rather than reconstructing the theory after implementation pressure appears.
