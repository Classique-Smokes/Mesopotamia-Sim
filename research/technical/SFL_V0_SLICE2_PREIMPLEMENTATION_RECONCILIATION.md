# SFL v0 Slice 2 — Pre-Implementation Reconciliation

**Status:** MASTER ARCHITECT RECONCILIATION COMPLETE / IMPLEMENTATION PLANNING READY WITH BOUNDED CAVEATS  
**Inputs:** authority inventory, implementation-surface map, verification-trigger map, Birth Run reconciliation, Roads corpus synthesis, Retired Vizier synthesis  
**Authority:** This file is operational reconciliation, not simulation semantics.

## 1. Bottom line

Slice 2 is **semantically ready for detailed implementation/verification planning** without reopening SFL v0, provided the plan stays inside the already accepted epistemic contract.

No Director-level semantic decision is required before planning if the slice is deliberately bounded to accepted acquisition/provenance/communication/recognition cases and avoids inventing general perception, trust, rumor, reputation, or a universal proposition algebra.

## 2. Accepted core to implement

The three discovery returns agree that Slice 2 should add bounded support for:

- persistent actor-specific `KnownFact` with provenance;
- persistent `Recognition` with `Unknown / Recognized / Contested`;
- automatic direct knowledge routes already accepted;
- `CommunicateClaim/Inform` as a voluntary personal action that transmits only a proposition the sender holds;
- sender/source/event provenance on communication;
- stale subjective state without passive synchronization;
- accepted precedence rules based on underlying evidence/event order rather than arrival order;
- `Contested` when accepted provenance/order rules do not resolve incompatible recognition evidence;
- actor-specific decision inputs and traces using the persistent epistemic state;
- bounded public/test inspection of subjective state without observer interference;
- preservation of commit-time objective revalidation.

## 3. Reuse rather than rewrite

Slice 1 already supplies:

- authoritative objective state and immutable snapshots;
- `PersonalInputCapture` as an actor-specific decision membrane;
- semantic event IDs, causal predecessors, cycle/reaction order;
- central proposal/response/resolution/commit sequencing;
- participant outcome learning with bounded reasons;
- one-personal-initiative accounting;
- deterministic decision traces;
- observer-noninterfering acceptance infrastructure.

Therefore Slice 2 is a **bounded extension of the kernel**, not a replacement.

## 4. Gaps that do not need to be solved now

The authority inventory identified several genuine general gaps. None must become a universal rule in Slice 2.

### General KnownFact conflict model

Do not invent a universal factual-belief state machine. Implement only the bounded fact/provenance cases required by accepted Slice-2 witnesses.

### General nonparticipant observation eligibility

Do not create a generic perception radius/visibility system.

Slice 2 can rely on accepted automatic direct knowledge plus communication unless a chosen acceptance witness truly requires a specific accepted observation rule.

If implementation later requires an indirect observation route not already fixed, escalate that exact event-specific question before coding it.

### Exhaustive evidence-strength algebra

Do not define one total ordering over all future evidence types.

Implement only the precedence relations already accepted.

### Autonomous communication-selection policy

The social semantics of when/whom/what to communicate remain open.

Verification may exercise communication through explicit laboratory policy/fixture control without claiming a historically meaningful autonomous communication motivation.

### Universal proposition/contradiction ontology

Do not design one.

Use the smallest typed proposition vocabulary needed for the accepted Slice-2 witnesses and preserve stable identity/provenance.

Any broader generalization can wait for later evidence.

## 5. Recognition causality without pulling later slices forward

Many canonical recognition examples use household/head state from Slices 3–4.

Slice 2 must **not** implement fake households or offices merely to make those tests runnable.

The minimal current-slice causal route is:

- actor holds an accepted factual or recognition proposition;
- that subjective state determines whether a corresponding `CommunicateClaim/Inform` candidate can exist;
- decision trace records the subjective basis;
- communication consumes personal initiative and creates provenance-bearing subjective effects in recipients.

This provides a real subjective-state → action-availability path using a Slice-2-native action.

Later household/head action gating remains deferred until the objective substrate exists.

Contested Recognition itself can be verified as persistent actor state and through communication/availability rules only where the accepted meaning is unambiguous; later authority-routing consequences remain deferred.

## 7. What the new tablets change

They do **not** change Slice-2 authority.

They improve the project's conceptual map.

### Roads corpus

The Roads collection demonstrates why route-dependent subjective state may eventually matter far beyond v0:

- mediated relationship prehistory;
- group information environments without group minds;
- distributed reputation;
- brokerage;
- plural network memory.

These belong in a sibling **Social Epistemic Dynamics** program because they can exist below institutional scale.

Current Slice 2 provides only the minimal substrate: actor-specific knowledge, provenance, communication, staleness, contestation.

Trust, rumor mutation, reputation and brokerage remain explicitly outside v0.

### Retired Vizier corpus

The Vizier collection mostly extends Institutional Dynamics with:

- role-conditioned salience/internalization;
- post-office social succession;
- residual influence/legitimacy versus current authority and competence;
- structural failure under sincere actors;
- institutional corrigibility through correction and sanctioned opposition.

These are mostly later-slice/post-v0 questions.

## 8. Birth Run interpretation after reconciliation

Birth Run 001 and the exploratory variants remain evidence of a narrow reference policy, not a defect in Slice-1 substrate.

Slice 2 should not be used as an excuse to make the agents broadly motivated.

Its value is to add **different subjective worlds** and make those differences causally inspectable.

Richer motivation, planning, trust, rumor, reputation, brokerage and role-shaped salience remain separate future problems.
