# RES-0001G — Household–Institution Interface Table

**Date:** 19 September 2026  
**Scope:** Old Babylonian Nippur; 14 documentary case rows / 15 text identifiers.  
**Status:** Advisory evidence; NO DESIGN DECISION.

This is the companion copy of §3.2 of `RES-0001G_RESULT.md`. It does not imply 14 distinct households. Eight cases are read through an old primary edition; three case rows use catalogue synopses (one combines two documents); three use a modern edition/documentary table. A joined case or republished text is not a new independent observation.

The sequence is person/household → institution/office → relation → resource/income → obligation/service → transmission → evidence → confidence. The final column flags overlap. Unknown obligations, household membership, dates and income remain unknown. Sources are defined below so this table is recoverable independently.
