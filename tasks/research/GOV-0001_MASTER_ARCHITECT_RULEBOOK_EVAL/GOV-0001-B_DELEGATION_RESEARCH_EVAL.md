**Context mode:** PROJECT-CONTEXT / fresh governance evaluation  
**Return:** `research/technical/GOV-0001/returns/GOV-0001-B_DELEGATION_RESEARCH_REPORT.md`

## Objective

Test whether the candidate rulebook routes delegated/open/adversarial work correctly without turning the constitutional core into an orchestration manual.

## Primary scenarios

### Scenario B1 — open technical research

A consequential technical problem has multiple plausible approaches and no accepted solution family.

Determine:
- whether the task should be PROJECT-CONTEXT or INDEPENDENT-CONTEXT and why;
- which protocol/template you load;
- how you avoid solution anchoring;
- when multiple agents are justified and why agent count itself is not evidence.

### Scenario B2 — blind replication / sentinel

A previous reviewer found a possible blocker. You want a fresh re-derivation that should not inherit the earlier conclusion.

Determine:
- how the control plane is constructed;
- what information must be withheld;
- what baseline/workspace rules apply;
- how contamination is handled.

### Scenario B3 — consequential architecture recommendation

A proposed optimization would introduce a new cache/derived-state mechanism with persistent coupling implications.

Determine:
- which owner governs architecture development;
- which owner governs escalation if implementation has already exposed the issue;
- whether the delegation protocol replaces either architecture owner.

### Scenario B4 — milestone drift review

A major subsystem milestone has just completed and assumptions/navigation may have gone stale.

Determine which audit protocol is loaded and what it must not do to higher authority.

## Second-pass audit

After primary results, inspect the inventory/reconciliation and check for lost baseline rules around context modes, anti-anchoring, provenance, synthesis, capability selection, artifact placement, and drift.

## Required return

Return PASS or BLOCK with:
- routing for each scenario;
- evidence of unnecessary protocol loading, if any;
- any duplicate/conflicting procedural ownership;
- control-plane blindness verdict;
- rule-loss verdict.
